## 注意事项

1：如果宫盘（比如说命宫）没有主星，此时应该把对宫的主辅星连同本宫盘的一起组合来看

2：疾厄宫往往不准，兄弟宫受到政策影响也可能不准，兄弟宫可以描述母亲，父母宫往往指代父亲

3：“会”表示三方，“照”表示对宫

4：四煞：擎羊， 陀罗， 火星， 铃星

### 辅佐八曜
辅曜：天魁，天铖，左辅，右弼

佐曜：文昌，文曲，禄存，天马

天魁：南斗，阳火，化阳贵，司才名，喜诸占不喜诸凶，十二宫皆暮。喜书生人。吉则得助，凶则得阻。

天铖：南斗，阴火，化阴贵，司才名，喜诸吉不喜诸凶，十二宫皆庙。喜夜生人。吉则得助，凶则受扰；

左辅：中天，阳土，主助力，行善令，喜诸吉不喜诸凶。忌居卯酉，余宮皆吉。吉则助伴，凶则侵扰。

右弼：中天，阴水，主助力 司制令，喜诸占不喜诸凶。忌居卯酉，余宫皆占。吉则助力，凶则掠夺。

文昌：南斗，阳金，工科甲亦主能文，喜诸吉。喜居中于辰巳酉丑。忌诸凶。忌居寅午戌。吉则优雅，凶则粉饰。

文曲：北斗，阴水，主科甲亦宅舌辩，喜忌同文昌。占則能言，凶则舌辩。

禄存：北斗，阴土，主爵禄，司贵寿，喜诸吉，最喜禄马交驰。不忌诸凶，唯忌空亡。喜子午卯西寅申巳亥。不居四墓。吉则财禄，凶则疾病。

天马：浮曜，阳火，主驿，司禄，主迁动，喜诸吉，尤喜禄存及生旺之地。忌诸凶，尤忌空亡及病死绝之乡。吉则灵动，凶则劳碌。



### 煞曜
擎羊， 陀罗， 火星， 铃星，地空，地劫

擎羊：北斗，阳金，主刑伤，喜诸占，喜四墓西北生人，喜居四墓。忌诸凶，忌子午卯酉。吉则权威，凶则刑伤。

陀罗：北助，阴金，化忌，主延缓，喜诸吉，喜四墓生人，喜居辰戌丑未。忌诸凶，忌寅申巳亥。吉则暗生权力，凶则暗受挤排。

火星：南助，阳火，化杀，主刚，喜诸吉，喜东南生人，喜寅卯巳午戌生人。喜居寅午戌。忌诸凶，忌居申子辰。吉则发越英华，凶则橫招灾厄。

铃星：南助，阴火，化杀，主烈，喜忌同火星。吉则暗中发福，凶则忌害暗侵。

地空：中天，阴火，主多灾，吉则为大度，喜诸吉，喜金火两行。庙火金二乡。忌诸凶，唯不忌火铃。陷水木二乡。

地劫：中天，阳火，主破失喜诸古，尤喜居辰戌。居余宮不占。忌诸凶。
